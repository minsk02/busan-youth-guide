# 테스트 계획 및 요구사항 추적표

작성일 2026-10-25 · 갱신일 2026-10-26 · 담당 계획 팀원 4 · 사용자 기능 테스트 미실행

이 문서는 구현 전 테스트 계획이다. 아래 항목은 통과 결과가 아니며 구현 후 실행 일시·실제 결과·증거를 기록한다. 초안 문서 검토와 실행 테스트도 구분한다.

## 테스트 방법

단위 테스트에서는 통제된 프로그램 데이터와 외부 서비스 대체 응답을 사용한다. 통합 테스트는 실제 API에서 수집한 데이터와 정규화·조회 사이의 연결을 확인한다. 시스템 테스트는 브라우저에서 사용자 흐름과 장애 안내를 확인한다.

통제 데이터는 테스트용 가상 자료임을 표시한다. 실제 API 호출 검증과 실제 데이터 기반 통합 검증을 대체하지 않는다. 현재 통제 데이터와 테스트 코드는 아직 작성하지 않았다.

각 테스트는 실행 전에 구체적인 입력 데이터와 예상 값을 작성한다. 자연어 조건 추출 평가 세트의 질문 수와 합격 기준은 지원 조건 확정 후 정한다. 환각 방지 기준은 평가 세트에서 근거 없는 사실 출력 0건을 목표로 제안하되 일반적인 무오류를 보장하지 않는다.

## API 검증 도구에서 수행한 확인

2026-10-26, Python 3.12 환경에서 실제 API 호출로 1,000건을 수집했다. 분야 필터의 표본·건수는 일치했으나 `paReStat=모집중`의 결과는 기대와 불일치했다. 상세 내용과 범위는 [API 검증 기록](data-api-review.md)을 따른다.

`python -m unittest discover -s tests -v`로 검증 도구의 오프라인 테스트 16개가 통과했다. 단일·빈 레코드, 업무·XML 오류, 페이지 누락·반복·상한·건수 변경, 날짜 경계·중복·URL 형식, 키 인코딩과 오류 메시지 노출 방지, 필터 불일치 보고·종료 코드를 확인했다. 이는 위 사용자 기능 TC-001~TC-016의 시스템 테스트 완료를 의미하지 않는다.
