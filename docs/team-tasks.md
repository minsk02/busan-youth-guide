## 저장소 소유자

백엔드·DB·API 연결과 공통 문서를 관리한다. 수집본과 테스트 결과를 확인하고 친구의 화면 PR을 검토한다. 교수님 양식에 문서를 옮긴 뒤 팀원 정보와 제출 파일명을 확인한다.

전달받은 frontend와 UI 사용 안내를 실행·검토한다. 검색 조건 확인, 비교 선택, 예외 안내를 직접 써보고 필요한 수정 사항을 반영한다. frontend 전용 브랜치로 PR을 올린다. [전달 방법](handoff.md)을 따른다.
