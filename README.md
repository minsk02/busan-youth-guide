# 부산청년 프로그램 찾기

소프트웨어공학 1분반 10팀 프로젝트입니다. 부산 청년 대상 프로그램을 자연어로 찾고, 조건에 맞는 추천을 확인하고, 관심 프로그램을 비교하는 웹 서비스입니다.

## 주요 기능

- 자연어 검색: 질문에서 조건을 읽고, 사용자가 확인한 조건으로 실제 데이터를 검색합니다.
- 맞춤 추천: 분야·키워드·대상 원문의 일치 정도를 계산해 추천 이유를 보여줍니다.
- 프로그램 비교: 선택한 2~3개 항목의 대상, 신청기간, 운영기간, 기관을 비교합니다.

LLM은 검색 조건을 해석하는 데 사용합니다. 프로그램 정보와 추천 이유는 공공데이터와 서버의 검색·점수 규칙에서 가져옵니다.

## 실행 방법

Python 3.12 기준입니다. PowerShell에서 프로젝트 폴더를 열고 실행합니다.

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

이미 `.env`가 있으면 복사하지 말고 필요한 설정만 추가합니다.

```dotenv
DATA_GO_KR_SERVICE_KEY=발급받은_키
OPENAI_API_KEY=발급받은_키
OPENAI_MODEL=gpt-4o-mini
```

처음 실행하거나 데이터를 갱신할 때 수집 명령을 실행합니다.

```powershell
.venv/Scripts/python.exe manage.py sync
```

서버를 켭니다.

```powershell
.venv/Scripts/python.exe app.py
```

브라우저에서 **http://127.0.0.1:8765**를 엽니다. SQLite를 사용하므로 별도 DB 서버 설치는 필요하지 않습니다. 수집한 데이터는 로컬 `data/app.db`에 저장됩니다. 화면을 사용하려면 `frontend/` 파일도 필요합니다.

## 사용 방법

1. 질문을 입력하고 '조건 읽기'를 누릅니다.
2. 해석된 조건을 확인하거나 수정합니다.
3. '이 조건으로 검색'을 눌러 결과를 확인합니다.
4. '맞춤 추천'에서 추천 이유를 확인합니다.
5. 관심 프로그램을 2~3개 선택하고 '비교하기'를 누릅니다.

## 데이터 출처

[부산광역시 청년지원프로그램 정보 API](https://www.data.go.kr/data/15163604/openapi.do)를 사용합니다. 프로그램 상세 정보에서 출처와 수집 시점을 확인할 수 있습니다.

원천 모집 상태 필터가 적용되지 않는 경우가 있어 서버에서 상태와 신청기간을 함께 확인합니다. 실제 접수 여부는 프로그램 홈페이지에서 확인해야 합니다. 홈페이지가 없거나 형식이 맞지 않으면 신청 링크를 표시하지 않습니다.

비용·주소·좌표는 전용 필드가 없어 무료·거리·세부 지역 조건은 지원하지 않습니다. 대상 키워드 검색은 원문을 찾는 기능이며 참가 자격을 판정하지 않습니다. 데이터 이용 시 제공기관의 이용조건을 따르고, 연결된 외부 홈페이지의 이미지·게시물은 해당 사이트의 권리를 별도로 확인해야 합니다.

인증키, 로컬 DB, 수집 원본은 Git에 올리지 않습니다. 원문 질문은 DB에 저장하지 않으며 조건 해석을 위해 OpenAI에 전달됩니다. AI 요청에는 `store=False`를 사용하고, 제공자의 보관 정책은 별도로 적용됩니다.

## 테스트

```powershell
.venv/Scripts/python.exe -m unittest discover -s tests -v
```

실제 DB와 OpenAI 연동은 아래 명령으로 확인합니다. API 키가 필요하며 소량의 호출 비용이 발생합니다.

```powershell
.venv/Scripts/python.exe scripts/smoke_test.py
```
