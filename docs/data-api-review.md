# 데이터 및 API 검증 기록

작성일 2026-10-25 · 상태 실제 호출 전

## 공식 소개에서 확인한 내용

출처: [공공데이터포털 부산광역시 청년지원프로그램 정보](https://www.data.go.kr/data/15163604/openapi.do)

2026-10-25 공식 페이지 확인 기준으로 제공기관은 부산광역시이며 REST, JSON/XML 형식으로 소개된다. 설명에는 청년 대상 지원사업 및 프로그램의 정책유형, 사업명, 지원대상, 신청·운영기간, 접수마감 여부, 주관기관, 문의처 등이 제시되어 있다.

페이지에는 무료, 실시간 갱신, 이용허락범위 제한 없음, 개발·운영 단계 자동승인, 개발계정 트래픽 1,000으로 표시된다. 트래픽 적용 단위와 실제 사용 조건은 신청 화면·활용 명세에서 추가 확인한다. 메타데이터의 실시간 표시는 개별 공고가 항상 최신임을 보장하는 것으로 해석하지 않는다. 외부 링크 페이지와 이미지의 이용조건도 동일하다고 가정하지 않는다.

## 검증 절차

1. 담당자가 본인 계정으로 활용신청하고 로컬 `.env`에 키를 저장한다.
2. 공식 요청 명세를 확인하고 최소 호출을 수행한다. HTTP 성공과 업무 응답 성공을 모두 확인한다.
3. 원본 응답은 기본적으로 Git에서 제외한 `data/raw/`에 저장한다. 로그와 요청 URL에 키를 노출하지 않는다.
4. 필드명·타입·결측값을 조사한다. 식별자, 페이지 처리, 중복, 신청기간과 운영기간 구분을 확인한다.
5. 현재 모집 항목 수와 필수 조건 누락 비율을 기록한다. 조사 범위를 샘플 또는 전체로 구분한다.
6. 공유할 응답 예시는 인증키·개인정보·재배포 조건을 검토한 뒤 별도 경로에 최소한으로 작성한다.
7. 실제 원본 필드와 내부 필드의 매핑을 아래 표에 작성하고 기능 범위를 결정한다.

## 내부 데이터 매핑 제안

아래 이름은 내부 설계안이며 API 실제 필드명이 아니다. 제공되지 않는 값은 null 또는 미상으로 처리한다.

| 내부 항목 | 원본 필드 | 확인할 내용 |
|---|---|---|
| source_id | 미확정 | 안정적인 원본 식별자 존재 여부 |
| title | 미확정 | 프로그램·사업명 |
| category | 미확정 | 유형 코드·표시명 |
| target_text | 미확정 | 대상 원문, 자동 자격 판정 가능 범위 |
| application_period_raw | 미확정 | 원문 보존, 신청기간과 운영기간 구분 |
| application_start / application_end | 미확정 | 명확히 파싱되는 경우에만 값 설정 |
| recruitment_status | 미확정 | 마감·상시·미상 등의 의미 |
| source_url | 미확정 | 프로그램별 공식 링크가 없으면 데이터 출처 링크 제공 |
| fetched_at | 애플리케이션 생성 | 실제 데이터 수집 시점, 원본 수정일과 구분 |
