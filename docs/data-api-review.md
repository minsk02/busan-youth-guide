# 데이터 및 API 검증 기록

최초 작성 2026-10-25 · 검증일 2026-10-26 · 버전 0.2

공식 명세를 확인하고 실제 API를 호출했다. 아래 결과는 2026-10-26 00:07 KST에 수집한 응답의 관측값이다. 공고의 실제 접수 가능 여부나 연결 페이지 내용까지 독립적으로 검증한 것은 아니다.

## 출처와 이용조건

출처: [공공데이터포털 부산광역시 청년지원프로그램 정보](https://www.data.go.kr/data/15163604/openapi.do)

공식 페이지 HTML에 포함된 `swaggerJson`에서 GET 경로와 요청·응답 명세를 확인했다. 공식 소개에는 REST, JSON/XML, 무료, 실시간 갱신, 이용허락범위 제한 없음, 개발·운영 단계 자동승인, 개발계정 트래픽 1,000으로 표시된다. 트래픽 적용 단위는 신청 상세에서 추가 확인해야 한다. 외부 홈페이지·이미지의 이용조건이 API와 같다고 가정하지 않는다.

## 실제 호출 결과

| 항목 | 확인 결과 |
|---|---|
| 기본 주소 | `https://apis.data.go.kr/6260000/YouthSupProgService` |
| 실제 조회 | `GET /getYouthSupProg` |
| 인증 | 쿼리 파라미터 `serviceKey`, 로컬 `.env`에서 읽음 |
| 필수 파라미터 | `serviceKey`, `pageNo`, `numOfRows`, `resultType` |
| 검증 요청 | `pageNo=1..10`, `numOfRows=100`, `resultType=json` |
| 정상 응답 | HTTP 200, `response.header.resultCode=00`, `resultMsg=NORMAL_CODE` |
| 응답 구조 | `response.body.items.item` 목록, 페이지 값과 전체 건수는 문자열 |
| 수집 범위 | API가 표시한 전체 1,000건을 100건씩 10페이지에서 수집 |
| 동일 레코드 | 원본 필드 전체가 같은 중복 3건, 전체 필드 기준 고유 레코드 997건 |
| 수집 시점 | `2026-10-26T00:07:20+09:00` 시작 기준, 원천 수정 시점과 구분 |

키를 넣은 정상 호출이 성공했으므로 사용 권한이 작동함을 확인했다. 포털의 신청 승인 화면 자체를 확인한 것은 아니다. 인증키가 포함된 요청 URL과 원본 응답은 Git에 올리지 않는다.

## 요청 필터 검증

명세의 선택 파라미터는 `busPlcNm`, `bizNm`, `aplyBgngYmd`, `aplyEndYmd`, `paReStat`이다. 날짜의 범위·동등 비교 의미와 사업명 부분 일치 여부는 미검증이다.

| 요청 | 실제 결과 | 해석 |
|---|---|---|
| `busPlcNm=교육분야` | 전체 395건으로 표시, 첫 100건 모두 교육분야, 로컬 집계 395건과 일치 | 해당 요청의 첫 페이지와 건수 검증 통과, 나머지 필터 페이지는 미수집 |
| `paReStat=모집중` | 전체 1,000건, 첫 100건에 모집마감 포함, 로컬 모집중 집계 96건과 불일치 | 이 요청에서는 필터가 기대대로 적용되지 않음 |

따라서 필수 조건 검증을 원천 API 필터에만 의존하지 않는다. 전체 수집본을 저장하고 서버에서 직접 조건을 적용한다. 위 관측만으로 모든 필터 값이나 제공기관 내부 오류 원인을 단정하지 않는다.

## 실제 응답 필드와 내부 매핑

아래 원본 필드명은 실제 응답에서 확인했다. 내부 필드명과 처리 규칙은 설계안이다. 전체 1,000건을 기준으로 null·빈 문자열·공백 문자열을 누락으로 집계했다.

| 원본 필드 | 의미 | 누락 | 내부 필드·처리 제안 |
|---|---|---|---|
| `busPlcNm` | 정책유형명 | 0 | `category` |
| `bizNm` | 사업명 | 0 | `title` |
| `trgtNm` | 대상명·조건 원문 | 0 | `target_text`, 나이 범위와 예외를 무리하게 확정하지 않음 |
| `aplyBgngYmd` | 신청시작일 | 0 | `application_start`, `YYYYMMDD` 검증 후 변환 |
| `aplyEndYmd` | 신청종료일 | 0 | `application_end`, 마감 시각은 제공하지 않음 |
| `schdlBgngYmd` | 일정시작일 | 0 | `schedule_start` |
| `schdlEndYmd` | 일정종료일 | 0 | `schedule_end` |
| `paReStat` | 원천 모집 상태 | 0 | `source_status`, 날짜 판정과 구분 |
| `mngtMson` | 주관기관명 | 0 | `organizer` |
| `inqryTlphnNo` | 문의 전화번호 | 137 | `contact_phone`, 없으면 확인 불가 |
| `hopgUrlAddr` | 홈페이지 URL | 175 | `homepage_url`, 신청 링크로 단정하지 않음 |
| `frstRegistPnttm` | 등록일자 | 0 | `source_registered_at`, 최종 수정일과 구분 |

관측한 12개 필드에는 전용 고유 ID, 주소, 좌표, 비용 필드가 없다. 수집 시점 `fetched_at`은 애플리케이션이 생성한다. 원본의 안정적인 ID는 확보되지 않았으므로 내부 ID와 중복·갱신 규칙을 별도로 설계해야 한다.

## 데이터 분포와 품질

| 항목 | 관측값 |
|---|---|
| 정책유형 | 교육 395, 참여·권리 290, 복지·문화 246, 일자리 61, 주거 8 |
| 원천 모집 상태 | 모집중 96, 모집마감 904 |
| 10월 26일이 신청기간 내인 레코드 | 96건, 시작·종료일을 포함하는 날짜 비교 기준 |
| 신청기간 종료 레코드 | 904건 |
| 신청기간 미상·역전 | 각 0건 |
| 네 날짜 필드의 `YYYYMMDD` 파싱 오류 | 각 0건 |
| 홈페이지 URL | HTTP(S) 형식 충족 815, 형식 부적합 10, 누락 175 |
| 등록일 범위 | 2026-03-19~2026-10-24 |

건수는 중복 제거 전 원본 레코드 기준이다. 96건을 서로 다른 프로그램 96개 또는 실제 접수 가능한 프로그램 96개로 단정하지 않는다. HTTP(S) URL 형식 검사는 홈페이지의 응답·내용·공식성·신청 가능 여부를 검증하지 않는다. 일부 사업명에 포함된 일정 표현과 날짜 필드의 수동 표본 대조에서 차이가 관찰되어, 날짜 필드만으로 공고 내용 전체의 정확성을 보장할 수 없다. 해당 불일치의 전체 건수는 조사하지 않았다.

## 개발 범위에 미치는 영향

- 검색·추천·비교를 위한 분야·대상·신청기간·운영기간 데이터가 있다.
- 모집 여부는 서버에서 날짜와 원천 상태를 함께 확인한다. 충돌하면 확인 필요로 표시하고 현재 모집 후보에서 제외한다. 마감 시각과 원문 접수 상태의 최종 확인은 사용자에게 안내한다.
- API의 모집 상태 필터는 검증 사례에서 실패했으므로 로컬 필터링을 기본으로 한다.
- 홈페이지 URL은 형식을 검증한 경우에만 외부 링크로 제공한다. 없거나 부적합하면 확인 불가로 표시하고 출처 링크는 별도로 제공한다.
- 비용·주소가 전용 필드로 없어 무료 조건 검색과 지도 표시는 초기 필수 범위에서 제외한다. 이미지 분석도 추가 기능 후보로 유지한다.
- 원천 ID가 없고 중복이 있어 정규화·중복 제거·갱신 규칙을 먼저 설계한다. 전체 필드 해시는 완전 중복 탐지에만 사용하고 영구 ID로 단정하지 않는다.

## 재현 방법과 산출물

Python 3.12에서 표준 라이브러리만 사용했다. 별도 패키지를 설치할 필요가 없다.

```powershell
python scripts/validate_youth_api.py --as-of 2026-10-26 --check-filters
python -m unittest discover -s tests -v
```

검증 스크립트 종료 코드: `0` 수집 완료·실행한 필터 점검 통과, `1` 호출·응답·파일 오류, `2` 수집 불완전, `3` 수집 완료이나 원천 필터 점검 불일치. 현재 관측 결과는 필터 불일치가 있어 `3`이 예상된다. 향후 데이터나 서비스가 바뀌면 수치·결과도 달라질 수 있다.

- [집계 보고서](../data/reports/youth-program-validation.json): 개인 레코드나 인증키 없이 공유 가능한 통계
- `data/raw/실행시각/page-*.json`: 로컬 전용 원본, Git 제외
- [오프라인 테스트](../tests/test_validate_youth_api.py): 페이지 처리·오류·날짜·키 인코딩·필터 불일치 보고 등 16개 통과
