# 부산 청년 프로그램 안내 AI 서비스

소프트웨어공학 1분반 10팀 프로젝트입니다. 부산 청년이 관심 분야와 참여 조건에 맞는 프로그램을 실제 공공데이터를 근거로 탐색하도록 돕는 웹 서비스를 계획합니다.

현재는 중간 발표를 위한 **계획 및 설계 초안 단계**입니다. 실제 API 수집·검증 스크립트를 작성해 1,000건의 응답을 확인했습니다. 사용자용 웹 서비스와 AI 연동은 아직 구현하지 않았습니다.

## 핵심 기능 후보

| 기능 | 동작 | 상태 |
|---|---|---|
| 자연어 검색 | 질문에서 조건을 추출하고 실제 데이터를 검색·필터링 | 설계 초안 |
| 맞춤형 추천 | 확인 가능한 조건으로 후보를 정렬하고 추천 근거 표시 | 설계 초안 |
| 프로그램 비교 | 선택한 프로그램의 대상·기간 등 실제 제공 정보를 비교 | 설계 초안 |

프로그램 상세 화면에는 확인된 정보, 출처, 데이터 수집 시점을 함께 표시합니다. 이미지 분석과 지도 연동은 추가 기능 후보이며 초기 필수 범위에 포함하지 않습니다. 실제 API 데이터 확인 후 범위를 확정합니다.

## 데이터 출처와 검증 상태

후보: [부산광역시 청년지원프로그램 정보 API](https://www.data.go.kr/data/15163604/openapi.do)

수집 시 HTTP 200·정상 코드 `00`을 확인하고 100건씩 10페이지, 전체 1,000건을 수집했습니다. 당시 신청기간에 해당하는 원본 레코드는 96건이었습니다. 실제 접수 가능 여부까지 검증한 것은 아닙니다.

분야 필터의 표본과 건수는 일치했지만 모집 상태 필터는 해당 검증 요청에서 적용되지 않았습니다. 서버에서 직접 조건을 검사하도록 설계합니다. 전용 비용·주소·고유 ID 필드는 없고 홈페이지 URL 누락·부적합과 중복도 있어 상세 내용은 데이터 검증 기록을 따릅니다.

## 로컬 설정

1. `.env.example`을 복사해 `.env`를 만듭니다.
2. 발급받은 API 인증키를 `.env`에만 입력합니다.
3. 아래 명령으로 API 수집·품질 집계를 실행합니다. Python 3.12 표준 라이브러리만 사용합니다.

```powershell
python scripts/validate_youth_api.py --check-filters
python -m unittest discover -s tests -v
```

수집 원본은 `data/raw/`에만 보관하고 Git에서 제외합니다. 공유 가능한 통계는 data/reports/youth-program-validation.json에 있습니다. 원천 필터 불일치가 발견되면 보고서를 저장한 후 종료 코드 `3`을 반환합니다. 현재 검증에서 모집 상태 필터 불일치를 관측했습니다.

실제 인증키, 사용자 이미지, 개인정보는 저장소나 문서에 넣지 않습니다.
