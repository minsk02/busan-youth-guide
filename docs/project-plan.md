# 프로젝트 계획서

버전 0.3 · 2026-10-26 · 소프트웨어공학 1분반 10팀

## 프로젝트 개요

프로젝트명은 '부산청년 프로그램 찾기'이다. 부산에서 교육·취업·문화 프로그램을 찾는 청년이 여러 공고의 대상과 신청기간을 확인하는 부담을 줄이려 한다. 공공데이터를 검색하고 사용자가 제시한 조건에 맞는 점과 확인이 필요한 점을 함께 보여주는 것이 목표다.

기존 공고 목록이나 홈페이지 검색도 사용할 수 있다. 본 서비스는 자연어 조건 정리, 추천 근거 표시, 여러 항목 비교에 초점을 둔다. 기존 서비스보다 우수하다는 사용자 평가를 수행한 것은 아니며, 편의성은 팀 사용자 점검으로 확인할 예정이다.

## 개발 범위

필수 기능은 자연어 검색, 조건 기반 추천, 2~3개 프로그램 비교이다. 상세 정보와 출처는 공통으로 제공한다. LLM은 조건 추출에 사용하며 실제 사실·추천 점수는 서버가 관리한다.

로그인, 장기 프로필, 신청 대행, 결제, 지도, 포스터 분석은 제외한다. 비용·주소의 전용 필드가 없으므로 무료나 지역구 조건 검색도 지원하지 않는다. 기능을 늘리기보다 검색 결과와 근거가 일치하는지 확인하는 데 시간을 쓰기로 했다.

## 사용자와 예시

주요 사용자는 부산에서 참여할 기회를 찾는 청년이다. '이번 달 신청할 수 있는 교육 프로그램'을 질문하면 조건을 확인한 뒤 검색한다. 두 프로그램이 마음에 들면 대상과 기간을 비교하고 원문 홈페이지를 확인한다. 대상 원문 검색은 참가 자격의 자동 확정을 뜻하지 않는다.

운영 담당자는 CLI 명령으로 데이터를 수집한다. 별도 관리자 화면은 만들지 않는다.

## 기술과 데이터

Python 3.12, Flask, SQLite, HTML/CSS/JavaScript, OpenAI gpt-4o-mini를 사용한다. 소규모 읽기 위주 서비스라 DB 서버 없이 실행 가능한 SQLite를 선택했다. 정해진 필드와 기간으로 검색할 수 있어 벡터 DB는 추가하지 않았다.

부산광역시 청년지원프로그램 API의 실제 1,000건을 확인했고 완전 중복 제거 후 997건을 저장했다. 모집 상태 필터 불일치가 있어 서버에서 날짜와 상태를 함께 검사한다. 링크 누락과 대상 조건의 한계는 [데이터 검증 기록](data-api-review.md)에 정리했다.

## 위험과 대응

- 외부 API가 실패하면 수집본을 교체하지 않고 이전 유효 데이터를 유지한다. 화면에는 수집 시점을 표시한다.
- AI가 조건을 잘못 읽을 수 있어 사용자가 확인·수정한 뒤 검색한다. API 실패 시 수동 조건 검색을 사용할 수 있다.
- 모집 상태와 날짜가 다르면 확인 필요로 표시하고 현재 신청기간 필터에서 제외한다.
- 원천 ID가 없어 수정 전후 동일 프로그램을 완벽히 추적하지 못한다. 이번 버전은 완전 중복 탐지와 최신 수집본 조회로 범위를 제한한다.
- 인증키·DB·원본 질문을 Git에 넣지 않는다. 홈페이지와 이미지의 권리는 API 이용조건과 따로 확인한다.
