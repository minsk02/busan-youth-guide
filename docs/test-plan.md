# 테스트 계획과 추적표

버전 0.3 · 2026-10-26

## 실행과 기록

```powershell
.venv/Scripts/python.exe -m unittest discover -s tests -v
.venv/Scripts/python.exe scripts/smoke_test.py
```

첫 명령은 외부 API를 사용하지 않는다. 두 번째는 실제 LLM과 수집된 DB를 사용한다. 유료 호출 여부를 구분하고 평가 질문에는 실명·연락처를 넣지 않는다.
